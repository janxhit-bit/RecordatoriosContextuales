# Recordatorios Contextuales — Actividad 1

Proyecto Android inicial desarrollado con Kotlin, Jetpack Compose y Material 3.

## Requisitos
- Android Studio compatible con Android Gradle Plugin 8.7.3.
- JDK 17.
- Android SDK 35.
- Emulador Android API 24 o superior, o dispositivo físico.

## Cómo abrir y ejecutar
1. Descomprime el ZIP.
2. Abre Android Studio y selecciona **Open** sobre la carpeta `Actividad1_ProgramacionMobile`.
3. Espera la sincronización de Gradle.
4. Si Android Studio solicita instalar SDK 35 o componentes, acepta la instalación.
5. Abre Device Manager y crea/inicia un emulador, o conecta un teléfono con depuración USB.
6. Pulsa **Run** (triángulo verde).

## Contenido implementado
- `Reminder`: data class inmutable con datos opcionales.
- `ReminderCategory` y `Priority`: enumeraciones.
- `ReminderStatus`: sealed class para estados.
- `List`: colección de recordatorios simulados.
- `Set`: categorías únicas.
- `Map`: asociación de categorías con colores.
- Filtros de recordatorios por estado y prioridad.
- Interfaz Compose con Material 3.
